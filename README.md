### Specialized Subsystems & Service Architecture

* **Core API (Java 21 + Spring Boot)**: Functions as the central web gateway handling user authentication, processing frontend dashboard traffic, and interacting directly with the Canvas LMS REST API.
* **Notification Worker Engine (C# / .NET)**: Built as a lightweight, performant background worker microservice. It consumes scheduling data from the database to manage background cron triggers and handle high-throughput routing to SendGrid and Twilio.
* **Predictive Insights Service (R)**: Executes analytics scripts over anonymized user submission data to generate student workload predictions, parsing submission times and grade patterns to feed predictive metrics back to the UI.
* **Frontend UI (React)**: Client-side dashboard that aggregates statistics from the Spring Boot API, hosting setting adjustment panels for notifications.
* **Database Layer (PostgreSQL)**: Serves as the central data storage repository, shared safely between the Spring Boot service and the C# background engine.
